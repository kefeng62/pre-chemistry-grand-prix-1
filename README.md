# 第一回化学グランプリ模試 Webサイト v2

## この版で修正した点
- 問ア〜問チ等の表示を、問題冊子の設問番号に対応する固定マッピングへ変更。特に第4問は **Q14〜Q27をすべて「問カ」** として表示。
- 第3問も、問題冊子の実際の設問ラベル（Q1〜Q29）に合わせて修正。
- 第4問 Q22 は **⑥・⑦のどちらも正解**として判定。したがって Q21〜Q23 の **568 / 578** の両方を正解として扱う。
- 第4問 Q37 は **⑤・⑥のどちらも正解**として判定。
- ラベル表示と採点用グループを分離し、同じ「問カ」の中で複数の採点グループがある場合にも正しく表示できるようにした。

## 注意
- 提供された解答解説PDFでは、第3問の配点表が本文・合計75点と整合していません。この版では、配点を勝手に創作せず、前版の採点グループを維持しています。第3問の正式な配点表が確定したら、そこだけ差し替えてください。
- 第4問の複数正答については、解答解説PDFに Q22「⑥ or ⑦」、Q37「⑤ or ⑥」と明記されています。
- localStorageを使用しているため、登録状態は同じブラウザ・同じ端末内でのみ保持されます。
- 本番運用で解答を完全に秘匿したい場合は、答え・採点をJavaScriptに置かず、サーバー側で採点する構成（例：Supabase）が必要です。

## GitHub Pages
1. GitHubに新しいリポジトリを作成
2. このフォルダの内容をアップロード
3. Settings → Pages → Deploy from a branch を選択
4. `main` / `root` を指定
5. 発行されたURLを開く
